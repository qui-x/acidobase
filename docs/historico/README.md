# Histórico da documentação

Os documentos desta pasta registram decisões e testes das rodadas anteriores. Não foram renomeados para sugerir que todos os comportamentos antigos continuam atuais. Para a entrega em uso, consulte [RC5.md](../RC5.md), [cobertura atual](../COBERTURA-RC5.md) e [validação](../../VALIDACAO.md).

Galerias, screenshots, logs e builds anteriores não são duplicados na distribuição RC.5. Suas referências históricas em texto não representam evidência executada nesta rodada. As suítes de regressão com nomes antigos foram executadas novamente e os seus JSON atuais estão em `tests/results/`.
